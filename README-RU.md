# Набор утилит WebScrabber

[Read in English (English Version)](README.md)

Набор легких JavaScript-скриптов для логирования сетевой активности, отслеживания событий DOM, мониторинга состояния хранилища и рекурсивного скачивания зависимостей страницы. Предназначен для запуска в консоли браузера (DevTools) или автоматического внедрения через расширения, такие как **Custom JS and CSS**.

---

## Рекомендуемый способ запуска

Для максимально эффективного использования рекомендуется запускать скрипты через расширение **Custom JS and CSS** (или аналогичные менеджеры пользовательских скриптов, такие как Tampermonkey / Violentmonkey):
* **Автоматическое внедрение:** Скрипт загружается сразу вместе с загрузкой страницы и мгновенно перехватывает самые первые сетевые запросы и инициализирующие события.
* **Ручной запуск:** Вы также можете скопировать и вставить код скрипта напрямую в консоль разработчика (`F12` -> `Console`).

## Стандарт метаданных в файлах

В начало каждого файла утилиты добавлен стандартный заголовок с метаданными в стиле расширений / UserScript:

## Варианты утилит

### 1. `WebScrabber.js` (Базовый логгер сети)
Легковесный перехватчик сетевых запросов, фиксирующий API-трафик с возможностью быстрого скачивания результатов.

* **Возможности:**
  * Перехват запросов `fetch` и `XMLHttpRequest` (XHR).
  * Сбор HTTP-методов, URL, тел запросов, статусов ответов и содержимого ответов сервера.
  * Плавающая кнопка (`💾 Скачать логи сети`) в правом нижнем углу для экспорта JSON в один клик.
* **Информация из заголовка:**
  * **Название:** WebScrabber
  * **Описание:** Базовый клиентский перехватчик и логгер сетевых запросов fetch и XHR.
  * **Автор:** Developer
  * **Версия:** 1.0.0
  * **Лицензия:** MIT

### 2. `WebScrabberFull.js` (Полный логгер сессий и краулер зависимостей)
Расширенный комплекс для полного аудита действий на странице, записи сессий и подготовки контекста для передачи в нейросети (LLM).

* **Возможности:**
  * **Сетевая активность:** Перехват `fetch`, `XHR`, `sendBeacon` и сообщений `WebSocket`.
  * **События пользователя и DOM:** Клики, ввод текста, отправка форм, навигация в SPA (`pushState`/`replaceState`), изменение размеров окна, JS-ошибки и кастомные события.
  * **Мониторинг состояния:** Начальный снимок и фиксация изменений (`diff`) в `document.cookie`, `localStorage`, `sessionStorage` и список БД `IndexedDB`.
  * **Безопасность:** Автоматическое маскирование чувствительных полей (пароли, банковские карты, одноразовые коды).
  * **Краулер зависимостей:** Рекурсивный сбор HTML, JS-скриптов и CSS-стилей в один итоговый текстовый файл. Первым в файле идёт `FILE0` — полный живой DOM (`document.documentElement.outerHTML`, то же самое, что скопировать `<html>` через «Edit as HTML» в Инспекторе; собственная панель скраббера из него вырезается), затем `FILE1`, `FILE2`, … (исходный HTML с сервера, inline-скрипты и стили, скачанные файлы).
  * **Параметры шума зависимостей** (раскрывающийся блок «Шум зависимостей» в панели):
    * *включать CSS в зависимости* — по умолчанию выкл.;
    * *включать популярные библиотеки/CDN* — по умолчанию выкл.;
    * *включать содержимое base64* — по умолчанию выкл. Пока галочка снята, содержимое base64 (`data:...;base64,...` и длинные строковые литералы base64) заменяется на `BASE64CODESKIP`, чтобы не засорять итоговый файл.
  * **Единый экспорт:** Выгрузка всей хронологической сессии в один JSON-файл, оптимизированный для анализа нейросетями.
  * **Панель управления:** Полнофункциональный плавающий интерфейс с переключателями, счетчиками и кнопками экспорта. Версия скрипта отображается в заголовке панели (`WebScrabberFull vX.X.X`) и в префиксе всех сообщений консоли (`[WebScrabberFull vX.X.X]`); задаётся константой `VERSION` в начале файла.
* **Информация из заголовка:**
  * **Название:** WebScrabberFull
  * **Описание:** Расширенный логгер клиентской активности (Сеть, События, Хранилище) и рекурсивный краулер зависимостей.
  * **Автор:** airmagicty
  * **Версия:** 2.X.X
  * **Лицензия:** MIT
